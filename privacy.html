Privacy Policy

Last updated: 13 November 2026

QzQGeo is a private tool used only by the owner of the QzQGeo channel.

What data the app uses

  • TikTok: the OAuth access and refresh tokens and the basic profile of the owner's own account (open id, username, privacy options), only to upload the owner's videos.
  • No data of any other TikTok user is collected, stored or shared.

Where it is kept

Tokens are stored only on the owner's own computer, in a private file. They are not sold, shared or sent anywhere except to TikTok's own API.

Deleting data

The owner can revoke access at any time in the TikTok app (Settings → Security → Apps and services); the local token file can be deleted at any time.
